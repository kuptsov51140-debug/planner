# Планировщик года

Локальное веб-приложение: цели на год с декомпозицией и отметками по дням,
дневник калорий, журнал тренировок со средними по весу и повторениям.
Никакого сервера — статичные HTML/CSS/JS файлы.

## Данные

Хранятся в `localStorage` браузера. На вкладке **Синхронизация** можно
подключить бесплатное хранилище [jsonbin.io](https://jsonbin.io), чтобы
видеть одни и те же данные на телефоне и компьютере — инструкция есть
прямо в приложении.

## Открыть на телефоне через GitHub Pages

1. Запушьте эту папку в свой репозиторий на GitHub (см. `git remote add
   origin ...` в истории команд или инструкцию в чате).
2. В репозитории: **Settings → Pages → Source → Deploy from a branch**,
   ветка `main`, папка `/ (root)`. Сохраните.
3. Через 1–2 минуты сайт появится по адресу
   `https://<ваш-логин>.github.io/<имя-репозитория>/`.
4. Откройте этот адрес на телефоне и на компьютере, настройте
   синхронизацию одинаковым ключом на обоих устройствах.
